# 2-Bit-Signed-Arithmetic-Unit

## Overview

This project implements a **2-bit signed arithmetic unit** using digital logic in **Logisim Evolution**.

The circuit operates on two 2-bit signed numbers and performs arithmetic operations based on the selected control input.

The project was designed to practice digital arithmetic, combinational logic, multiplexing, and the implementation of signed binary operations.

## Features

* 2-bit signed arithmetic
* Combinational logic design
* Arithmetic operation selection
* Binary input and output
* Designed and simulated using Logisim Evolution

## Number Representation

The circuit uses **2's complement** to represent signed 2-bit numbers.

|selector| meaning |
| ------ | ------: |
| `00`   |Not used |
| `01`   |  Add    |
| `10`   |Subtract |
| `11`   |multiply |
